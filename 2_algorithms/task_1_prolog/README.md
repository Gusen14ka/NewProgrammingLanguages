# Задача о расстановке N ферзей (рекурсия)

**Тема:** Алгоритмическая задача — Prolog

## Описание задачи

Нужно расставить N ферзей на шахматной доске N×N так, чтобы ни один не бил другого:
никакие два ферзя не должны стоять на одной горизонтали, вертикали или диагонали.
Программа находит все такие расстановки, печатает их количество и рисует доску для
первой найденной.

Расстановка хранится списком из N чисел: k-й элемент — номер строки, в которой стоит
ферзь в k-м столбце. Так по одному ферзю в столбце получается автоматически.

Решение рекурсивное. Предикат `place` берёт из списка ещё не занятых строк одну строку
(`select`) — так строки тоже не повторяются, — проверяет предикатом `safe`, что
новый ферзь не стоит на одной диагонали ни с одним из уже поставленных (на одной
диагонали ферзи, у которых разница строк равна расстоянию между столбцами), и
рекурсивно вызывает себя для следующего столбца.

Если подходящей строки нет, срабатывает встроенный в Prolog перебор с возвратом
(backtracking): интерпретатор сам возвращается к предыдущему выбору и пробует
следующий вариант. Готовые библиотеки ограничений (например, `clpfd`) не
используются. Все решения собираются встроенным предикатом `findall`.

## Формат входных и выходных данных

Входные данные — необязательный аргумент командной строки N (по умолчанию 8).
Выходные данные — число решений, первое решение в виде списка и доска, где `Q` —
ферзь, `.` — пустая клетка.

## Запуск

Нужен SWI-Prolog (`sudo apt install swi-prolog`).

```bash
swipl queens.pro       # N = 8 → 92 решения
swipl queens.pro 4     # N = 4 → 2 решения
swipl queens.pro 10
```
