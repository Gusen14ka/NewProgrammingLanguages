# Задача о расстановке N ферзей (рекурсия)

**Тема:** Алгоритмическая задача — Prolog

## Описание задачи

Классическая задача о расстановке N ферзей на доске N×N так, чтобы ни один ферзь не
бил другого. Позиция представляется списком из N чисел, где индекс — номер столбца, а
значение — номер строки, в которой стоит ферзь этого столбца.

Основной рекурсивный предикат перебирает возможные строки для очередного столбца по
одной, на каждом шаге явным предикатом `safe` проверяя, что новый ферзь не бьёт ни
одного из уже расставленных: не совпадает строка, не совпадает диагональ (разница
строк равна разнице столбцов). Если для текущего столбца безопасной позиции не
находится, происходит автоматический откат (backtracking) к предыдущему столбцу за
счёт механизма перебора Prolog — без использования готовых библиотечных предикатов
вроде `clpfd`. Программа находит все решения для заданного N (через `findall`) и
печатает общее количество решений и ASCII-изображение доски для одного из них.

## Формат входных и выходных данных

Входные данные — число N (размер доски и число ферзей).
Выходные данные — количество решений и ASCII-доска (`.` — пустая клетка, `Q` —
ферзь) для одного из найденных решений.
