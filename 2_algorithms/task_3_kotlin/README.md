# Поиск подстроки алгоритмом Кнута–Морриса–Пратта

**Тема:** Алгоритмическая задача — Kotlin

## Описание задачи

Программа находит все вхождения образца (pattern) в тексте алгоритмом
Кнута–Морриса–Пратта (KMP) и сравнивает его с наивным поиском по числу посимвольных
сравнений. Встроенные функции поиска подстрок (`indexOf` и т. п.) не используются.

Наивный поиск прикладывает образец к каждой позиции текста и сравнивает символы
слева направо; при несовпадении сдвигается на одну позицию и начинает сравнение
заново. В худшем случае это O(n · m) сравнений, где n — длина текста, m — длина
образца.

KMP никогда не возвращается назад по тексту. Для этого заранее строится
префикс-функция образца: для каждой позиции i — длина самого длинного собственного
префикса образца, который одновременно является суффиксом его первых i + 1 символов.
При несовпадении она подсказывает, сколько уже совпавших символов можно не проверять
повторно. Итоговая сложность — O(n + m).

Для наглядности есть демо-режим: текст из 100 000 букв `a` с `b` в конце и образец из
50 букв `a` с `b` в конце. Это худший случай для наивного поиска.

## Формат входных и выходных данных

Входные данные — текст и образец: двумя аргументами командной строки, вводом с
консоли (если аргументов нет) или аргумент `demo` для демонстрационного примера.
Выходные данные — префикс-функция образца (для коротких образцов), список позиций
вхождений (с нуля), число сравнений у KMP и у наивного поиска, проверка совпадения
результатов.

## Запуск

Нужен компилятор Kotlin (`kotlinc`) и Java. Компилятор можно поставить через SDKMAN
(`sdk install kotlin`) или скачать архив с GitHub-релизов Kotlin.

```bash
kotlinc Kmp.kt -include-runtime -d kmp.jar
java -jar kmp.jar abacabadabacaba abacaba
java -jar kmp.jar demo
java -jar kmp.jar            # ввод текста и образца с консоли
```
