# Поиск подстроки алгоритмом Кнута-Морриса-Пратта

**Тема:** Алгоритмическая задача — Kotlin

## Описание задачи

Программа реализует точный поиск всех вхождений образца в тексте алгоритмом
Кнута-Морриса-Пратта (KMP), без использования стандартных функций поиска подстрок
языка. Сначала по шаблону вручную строится префикс-функция (массив длин наибольшего
собственного префикса, совпадающего с суффиксом, для каждого префикса шаблона).
Затем выполняется проход по тексту одним указателем: при несовпадении символов
позиция в шаблоне сдвигается назад с помощью префикс-функции вместо возврата назад по
тексту, что даёт линейную сложность O(n + m).

Для сравнения программа дополнительно реализует наивный алгоритм поиска подстроки (с
явным вложенным циклом и возвратом назад при несовпадении) и подсчитывает число
посимвольных сравнений, выполненных каждым из двух алгоритмов на одном и том же
тексте и шаблоне, чтобы наглядно показать разницу в эффективности.

## Формат входных и выходных данных

Входные данные — текст и образец для поиска (строки с консоли или константы).
Выходные данные — список позиций всех вхождений образца в текст, число сравнений
символов у алгоритма KMP и у наивного алгоритма.
