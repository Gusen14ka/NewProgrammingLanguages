# Компоненты связности графа через рекурсивный DFS (рекурсия)

**Тема:** Алгоритмическая задача — Julia

## Описание задачи

Программа находит все компоненты связности неориентированного графа. Граф задаётся
списком рёбер (пар вершин), считываемым из текстового файла или заданным в коде, и
преобразуется в список смежности.

Для поиска компонент используется рекурсивная функция обхода в глубину (DFS):
начиная с произвольной непосещённой вершины, функция помечает её как посещённую,
добавляет в текущую компоненту и рекурсивно вызывает себя для каждого непосещённого
соседа. Главный цикл программы перебирает все вершины графа, и для каждой ещё не
посещённой вершины запускает новый обход DFS, порождая новую компоненту связности. По
завершении обхода печатается список найденных компонент (каждая — список входящих в
неё вершин), их размеры и общее число компонент.

## Формат входных и выходных данных

Входные данные — список рёбер графа (текстовый файл вида "A B" на строку либо
константа в коде), число вершин.
Выходные данные — список компонент связности с перечислением вершин, размер каждой
компоненты, общее число компонент.
