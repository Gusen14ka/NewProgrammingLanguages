# Построение кода Хаффмана (рекурсия)

**Тема:** Алгоритмическая задача — F#

## Описание задачи

Код Хаффмана — способ сжатия текста без потерь: частые символы кодируются короткими
последовательностями битов, редкие — длинными. Программа строит такой код для
заданного текста, кодирует текст, считает степень сжатия по сравнению с обычной
кодировкой ASCII (8 бит на символ) и, для проверки, декодирует результат обратно.

Сначала считается, сколько раз встречается каждый символ. Каждый символ становится
листом дерева с весом, равным частоте. Затем рекурсивная функция `build` на каждом
шаге сортирует узлы по весу, берёт два самых лёгких, объединяет их в новый узел с
суммарным весом и вызывает себя снова — пока не останется один узел, корень дерева.

Коды получаются рекурсивным обходом дерева (функция `codes`): шаг в левое поддерево
добавляет к коду `0`, в правое — `1`, а путь от корня до листа и есть код символа.
Ни один код не является началом другого (префиксный код), поэтому закодированный
текст однозначно декодируется без разделителей. Декодирование (`decode` / `walk`)
тоже рекурсивно: по битам спускаемся от корня до листа, записываем символ и
начинаем с корня снова.

Дерево описано алгебраическим типом данных `Tree` (`Leaf` — лист с символом, `Node` —
узел с двумя потомками), а все функции разбирают его через сопоставление с образцом
(`match`).

## Формат входных и выходных данных

Входные данные — необязательный аргумент: строка текста или путь к текстовому файлу
(по умолчанию используется встроенная строка).
Выходные данные — таблица «символ — частота — код», начало закодированной битовой
строки, размер в битах до и после, процент сжатия и проверка декодирования.

## Запуск

Нужен .NET SDK (`sudo apt install dotnet-sdk-8.0`).

```bash
dotnet fsi huffman.fsx
dotnet fsi huffman.fsx "my own text to compress"
dotnet fsi huffman.fsx some_file.txt
```
