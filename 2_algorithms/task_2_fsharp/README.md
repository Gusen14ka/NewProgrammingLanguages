# Построение кода Хаффмана (рекурсия)

**Тема:** Алгоритмическая задача — F#

## Описание задачи

Программа принимает на вход произвольный текст, считает частоту встречаемости
каждого символа и строит по этим частотам оптимальный префиксный код Хаффмана.
Построение дерева реализовано рекурсивно: на каждом шаге среди текущего списка узлов
(изначально — по одному листу на символ с его частотой) выбираются два узла с
наименьшей частотой, объединяются в новый внутренний узел с суммарной частотой, и это
повторяется, пока не останется один узел — корень дерева.

После построения дерева рекурсивный обход от корня до каждого листа формирует код
переменной длины для каждого символа (0 — уход влево, 1 — уход вправо). Далее
исходный текст кодируется полученными кодами, считается суммарная длина закодированного
текста в битах и сравнивается с длиной, которая потребовалась бы при фиксированных
8 битах на символ (обычный ASCII), выводится процент сжатия.

## Формат входных и выходных данных

Входные данные — текст (строка-константа, аргумент командной строки или файл).
Выходные данные — таблица кодов для каждого символа, длина текста в битах до и
после кодирования, процент сжатия.
