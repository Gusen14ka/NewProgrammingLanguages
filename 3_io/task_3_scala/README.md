# Калькулятор расходов с историей операций в CSV-файле

**Тема:** Ввод/вывод в консоль и файл — Scala

## Описание задачи

Консольное приложение для учёта личных финансов. При старте программа читает
существующий CSV-файл истории операций (если он есть; формат: дата, тип операции —
доход/расход, категория, сумма) и вычисляет текущий баланс и суммы по категориям.

Далее в цикле пользователь вводит новые операции в формате `<тип> <категория>
<сумма>` (например, `expense food 450` или `income salary 50000`); каждая корректно
введённая операция сразу дописывается новой строкой в CSV-файл вместе с текущей
датой, а баланс и сводка по категориям пересчитываются в памяти. Команда `report`
выводит текущий баланс и таблицу суммарных расходов/доходов по каждой встретившейся
категории, команда `exit` завершает программу. Некорректный ввод (неизвестный тип
операции, нечисловая сумма) обрабатывается с выводом сообщения об ошибке без
прерывания работы.

## Формат входных и выходных данных

Входные данные — CSV-файл истории операций на диске, команды с консоли.
Выходные данные — обновляемый CSV-файл, отчёт по категориям на экране по команде
`report`.
