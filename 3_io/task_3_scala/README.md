# Калькулятор расходов с историей операций в CSV-файле

**Тема:** Ввод/вывод в консоль и файл — Scala

## Описание задачи

Консольное приложение для учёта личных финансов. Все операции хранятся в CSV-файле
(CSV — текстовая таблица, где значения в строке разделены запятыми) с колонками:
дата, тип (`income` — доход или `expense` — расход), категория, сумма.

При запуске программа читает существующий файл истории (если он есть), пропуская
заголовок и повреждённые строки, и сразу печатает сводку: текущий баланс и суммы по
категориям отдельно для доходов и расходов.

Дальше пользователь в цикле вводит операции в формате `<тип> <категория> <сумма>`,
например `expense food 450.50` или `income salary 50000`. Каждая корректная операция
вместе с сегодняшней датой сразу дописывается в конец CSV-файла. Команда `report`
печатает актуальную сводку, `exit` завершает работу. Неизвестный тип операции,
нечисловая или неположительная сумма, неверное число слов — всё это выдаёт
сообщение об ошибке без остановки программы.

Суммы хранятся в `BigDecimal`, чтобы не было ошибок округления, свойственных обычным
дробным числам (`0.1 + 0.2 ≠ 0.3`). Операция описана case-классом `Operation`, а
результат разбора ввода — типом `Either`: либо ошибка (`Left`), либо операция
(`Right`).

## Формат входных и выходных данных

Входные данные — CSV-файл истории (необязательный аргумент, по умолчанию
`expenses.csv`) и команды с консоли.
Выходные данные — дополняемый CSV-файл и сводка по категориям в консоли.

## Запуск

Нужны Scala и Java (`sudo apt install scala` или через Coursier `cs setup`).

```bash
scalac Expenses.scala
scala Expenses                 # файл expenses.csv
scala Expenses my_budget.csv
```
