# Построчное сравнение двух текстовых файлов (упрощённый diff)

**Тема:** Ввод/вывод в консоль и файл — Haskell

## Описание задачи

Программа сравнивает два текстовых файла построчно и показывает различия в стиле
утилиты `diff`: строки без изменений печатаются с двумя пробелами, удалённые (есть
только в первом файле) — со знаком `-`, добавленные (есть только во втором) — со
знаком `+`. В конце — сводка: сколько строк добавлено, удалено и не изменилось.
Отчёт выводится в консоль и сохраняется в файл `diff_report.txt`.

Чтобы различий было как можно меньше, программа ищет наибольшую общую
подпоследовательность строк (LCS, longest common subsequence) — самый длинный набор
строк, который встречается в обоих файлах в одном и том же порядке (не обязательно
подряд). Эти строки считаются неизменными, всё остальное — удалением или добавлением.

LCS считается динамическим программированием: таблица `lcs`, где в ячейке (i, j)
записана длина LCS для концов файлов, начиная с i-й строки первого и j-й строки
второго. Таблица заполняется лениво: в Haskell значение ячейки вычисляется только
тогда, когда оно понадобилось, поэтому её можно описать прямо через саму себя.
Затем функция `walk` проходит по таблице от начала и восстанавливает список изменений.
Готовые библиотеки сравнения текстов не используются.

## Формат входных и выходных данных

Входные данные — пути к двум файлам (аргументами или ввод с консоли). Примеры —
`old.txt` и `new.txt`.
Выходные данные — построчный отчёт с пометками `-`/`+` и сводкой в консоли и в
`diff_report.txt`.

## Запуск

Нужен компилятор GHC (`sudo apt install ghc`).

```bash
ghc -O Diff.hs -o diff
./diff old.txt new.txt
cat diff_report.txt
```
