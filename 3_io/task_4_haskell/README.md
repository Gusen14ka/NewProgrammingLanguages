# Построчное сравнение двух текстовых файлов (упрощённый diff)

**Тема:** Ввод/вывод в консоль и файл — Haskell

## Описание задачи

Программа принимает пути к двум текстовым файлам и построчно сравнивает их
содержимое, показывая различия в стиле утилиты `diff`. Для нахождения соответствия
между строками используется алгоритм поиска наибольшей общей подпоследовательности
(LCS), реализованный через таблицу динамического программирования, без обращения к
специализированным библиотекам сравнения текстов.

По построенной таблице LCS восстанавливается последовательность операций: строки,
присутствующие в обоих файлах в общем порядке, помечаются как совпадающие, строки,
отсутствующие во втором файле, — знаком `-` (удалённые), строки, отсутствующие в
первом файле, — знаком `+` (добавленные). Построчный отчёт с такими пометками
одновременно печатается на экран и сохраняется в отдельный файл результата сравнения,
в конце дополнительно печатается краткая сводка: сколько строк добавлено, сколько
удалено, сколько совпало.

## Формат входных и выходных данных

Входные данные — пути к двум сравниваемым текстовым файлам.
Выходные данные — построчный отчёт о различиях на экране и в файле, итоговая сводка
чисел добавленных/удалённых/совпадающих строк.
