# Посимвольная и пословная статистика текстового файла

**Тема:** Ввод/вывод в консоль и файл — Objective-C

## Описание задачи

Программа принимает путь к текстовому файлу (аргументом командной строки или
запросом с консоли), построчно читает его содержимое и собирает статистику: общее
число строк, общее число слов, самое длинное встретившееся слово (и его длину), а
также частоту встречаемости каждой буквы латинского алфавита без учёта регистра
(знаки препинания и цифры игнорируются).

Сводка выводится на экран в читаемом виде: число строк/слов, самое длинное слово и
таблица «буква — количество», отсортированная по убыванию частоты. Кроме вывода на
экран, программа дописывает новую запись в отдельный файл-журнал статистики: дату
запуска, имя проанализированного файла и итоговые числа, не затирая предыдущие
записи, — так журнал накапливает историю запусков программы на разных файлах.

## Формат входных и выходных данных

Входные данные — путь к анализируемому текстовому файлу.
Выходные данные — статистика на экране; добавленная запись в файле-журнале
статистики.
