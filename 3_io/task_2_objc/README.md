# Посимвольная и пословная статистика текстового файла

**Тема:** Ввод/вывод в консоль и файл — Objective-C

## Описание задачи

Программа читает текстовый файл и считает по нему статистику:

- число строк;
- число слов (слово — непрерывная последовательность букв, всё остальное —
  разделители);
- самое длинное слово и его длину;
- частоту каждой буквы латинского алфавита без учёта регистра.

Результат выводится в консоль; частоты букв печатаются по убыванию вместе с
текстовой гистограммой из символов `#`. Кроме того, программа дописывает в конец
файла-журнала `stats_log.txt` строку с датой запуска, именем файла и итоговыми числами,
не затирая предыдущие записи, — так копится история запусков.

Подсчёт вынесен в класс `TextStats`. Используется только стандартная библиотека
Foundation (`NSString` для чтения файла и разбора текста, `NSFileHandle` для дозаписи
в журнал). Код совместим как с GNUstep в Linux, так и с macOS.

## Формат входных и выходных данных

Входные данные — путь к текстовому файлу (аргументом командной строки или ввод с
консоли). Пример — `sample.txt`.
Выходные данные — статистика в консоли и новая строка в `stats_log.txt`.

## Запуск

В Linux/WSL нужен GNUstep (`sudo apt install gobjc gnustep-devel`).

```bash
gcc -std=gnu11 $(gnustep-config --objc-flags) textstats.m -o textstats $(gnustep-config --base-libs)
./textstats sample.txt
cat stats_log.txt
```
