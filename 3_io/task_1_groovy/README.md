# Консольный органайзер заметок с хранением в файле

**Тема:** Ввод/вывод в консоль и файл — Groovy

## Описание задачи

Интерактивная консольная программа для ведения списка заметок. В цикле программа
читает команды: `add <текст> #тег1 #тег2` — добавить заметку с текстом и опциональными
тегами; `list` — вывести все заметки с номером, датой создания и тегами; `search
<слово>` — найти заметки, содержащие слово в тексте или среди тегов; `remove <номер>`
— удалить заметку по номеру; `exit` — сохранить состояние и завершить работу.

Все заметки хранятся в текстовом файле в собственном простом формате (одна заметка —
одна строка с полями, разделёнными служебным символом, теги через запятую). При
запуске программа читает существующий файл заметок (если он есть) и восстанавливает
список в память; после каждой изменяющей операции (add/remove) файл перезаписывается
целиком. Некорректные команды и номера заметок обрабатываются с выводом понятного
сообщения об ошибке, без падения программы.

## Формат входных и выходных данных

Входные данные — команды с консоли по описанному синтаксису.
Выходные данные — списки и результаты поиска на экране; файл заметок на диске в
собственном текстовом формате.
