# Консольный органайзер заметок с хранением в файле

**Тема:** Ввод/вывод в консоль и файл — Groovy

## Описание задачи

Интерактивная консольная программа для ведения заметок. В цикле она читает команды с
клавиатуры:

- `add <текст> #тег1 #тег2` — добавить заметку; слова с `#` становятся тегами;
- `list` — показать все заметки с номером, датой создания и тегами;
- `search <слово>` — найти заметки, где слово встречается в тексте (без учёта
  регистра) или совпадает с тегом;
- `remove <номер>` — удалить заметку по номеру;
- `help` — подсказка, `exit` — сохранить и выйти.

Заметки хранятся в текстовом файле в собственном формате: одна заметка — одна строка
вида `дата|тег1,тег2|текст`. При запуске файл читается и заметки восстанавливаются в
память; после каждого изменения (`add`, `remove`) файл перезаписывается целиком, так
что данные не теряются даже при аварийном закрытии. Неверные команды, пустой текст и
неправильный номер заметки обрабатываются сообщением об ошибке без падения программы.

## Формат входных и выходных данных

Входные данные — команды с консоли; необязательный аргумент — путь к файлу заметок
(по умолчанию `notes.txt` в текущей папке).
Выходные данные — ответы на команды в консоли и файл заметок на диске.

## Запуск

Нужен Groovy (`sudo apt install groovy`).

```bash
groovy notes.groovy              # файл notes.txt
groovy notes.groovy my_notes.txt
```
