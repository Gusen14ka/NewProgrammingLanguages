# Конвертер JSON в S-выражения

**Тема:** Конвертация данных — OCaml

## Описание задачи

Программа читает произвольный JSON-документ (объекты, массивы, строки, числа,
`true`/`false`/`null`) из файла и разбирает его собственным рекурсивным нисходящим
парсером (без сторонних библиотек работы с JSON) в промежуточное алгебраическое
представление — рекурсивный тип данных с вариантами для объекта, массива, строки,
числа и булевых/null значений.

Затем это представление рекурсивно печатается в виде S-выражений в стиле Lisp:
JSON-объект `{"a": 1, "b": true}` превращается в список пар `((a . 1) (b . true))`,
JSON-массив `[1, 2, 3]` — в список значений `(1 2 3)`, строки оборачиваются в кавычки,
числа и булевы значения печатаются как атомы. Вложенные объекты и массивы печатаются с
сохранением вложенности скобок и, по возможности, с отступами для читаемости.
Результат выводится на экран и сохраняется в текстовый файл с расширением `.sexp`.

## Формат входных и выходных данных

Входные данные — JSON-файл произвольной вложенности.
Выходные данные — файл с эквивалентным S-выражением и тот же текст на экране.
