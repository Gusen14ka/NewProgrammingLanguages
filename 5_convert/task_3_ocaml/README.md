# Конвертер JSON в S-выражения

**Тема:** Конвертация данных — OCaml

## Описание задачи

Программа читает JSON-документ произвольной вложенности и записывает его в виде
S-выражений — скобочной записи, которая используется в языках семейства Лисп. Разбор
JSON написан вручную, без библиотек.

Разбор — рекурсивный спуск (recursive descent): для каждой конструкции JSON есть своя
функция — `parse_value`, `parse_object`, `parse_array`, `parse_string`,
`parse_number`, — и они вызывают друг друга по мере вложенности документа. Результат —
дерево типа `json`, алгебраического типа данных с вариантами `Null`, `Bool`, `Number`,
`String`, `Array` и `Object`. В строках обрабатываются все escape-последовательности
JSON, включая `\uXXXX` (символ Unicode по коду). При ошибке в JSON программа сообщает
позицию и причину.

Правила преобразования в S-выражения:

| JSON | S-выражение |
|------|-------------|
| `{"a": 1, "b": true}` | `((a . 1) (b . true))` — список пар «ключ . значение» |
| `[1, 2, 3]` | `(1 2 3)` |
| `"text"` | `"text"` |
| `null` | `nil` |
| `[]`, `{}` | `()` |

Ключи из букв, цифр, `-` и `_` записываются как символы без кавычек, остальные — как
строки. Вывод форматируется: короткие выражения — в одну строку, длинные разбиваются
по строкам с выравниванием вложенных элементов.

## Формат входных и выходных данных

Входные данные — JSON-файл (аргумент, по умолчанию `data.json`, пример приложен).
Выходные данные — S-выражение на экране и в файле (второй аргумент, по умолчанию то же
имя с расширением `.sexp`).

## Запуск

Нужен OCaml (`sudo apt install ocaml`).

```bash
ocamlopt json2sexp.ml -o json2sexp
./json2sexp data.json
```

Или без компиляции: `ocaml json2sexp.ml data.json`.
