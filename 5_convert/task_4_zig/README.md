# Конвертер BMP-изображения в ASCII-art

**Тема:** Конвертация данных — Zig

## Описание задачи

Программа читает файл простого несжатого 24-битного BMP-изображения: вручную
разбирает заголовок файла и заголовок изображения (без библиотек работы с
изображениями), определяя ширину, высоту и смещение до начала пиксельных данных,
после чего читает пиксели построчно с учётом выравнивания строк BMP по границе 4 байт
и того, что строки в BMP обычно хранятся снизу вверх.

Для каждого пикселя вычисляется яркость (оттенок серого) по значениям каналов R, G, B
(взвешенной суммой), и полученное значение отображается на символ из заранее заданной
палитры плотности символов (например, `@%#*+=-:. `, от тёмного к светлому). Так как
символы в терминале обычно выше, чем широкие, при формировании результата по
вертикали пиксели могут группироваться по несколько строк в один символ ASCII-строки,
чтобы итоговое изображение не было визуально растянутым. Результат построчно
выводится в консоль и сохраняется в текстовый файл.

## Формат входных и выходных данных

Входные данные — путь к 24-битному несжатому BMP-файлу.
Выходные данные — текстовое ASCII-изображение на экране и сохранённое в текстовый
файл.
