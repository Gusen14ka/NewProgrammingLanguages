# Конвертер BMP-изображения в ASCII-art

**Тема:** Конвертация данных — Zig

## Описание задачи

Программа превращает картинку в формате BMP в «рисунок» из текстовых символов. Формат
BMP разбирается вручную, без библиотек для работы с изображениями.

BMP-файл начинается с заголовка, из которого программа читает (числа хранятся в
порядке little-endian — младший байт первым):

- сигнатуру `BM` — признак BMP-файла;
- смещение до начала пикселей (байт 10);
- ширину и высоту (байты 18 и 22); отрицательная высота означает, что строки
  хранятся сверху вниз, положительная — снизу вверх (так чаще всего);
- глубину цвета (байт 28) — поддерживаются 24 и 32 бита на пиксель;
- тип сжатия (байт 30) — поддерживаются только несжатые файлы.

Каждая строка пикселей в BMP дополнена нулями до длины, кратной 4 байтам, — это
учитывается при расчёте адреса пикселя. Цвет пикселя хранится в порядке B, G, R.

Для каждого пикселя считается яркость по формуле `0.299·R + 0.587·G + 0.114·B` (глаз
по-разному чувствителен к цветам, зелёный кажется самым ярким). Картинка
уменьшается: пиксели объединяются в блоки, и берётся средняя яркость блока. По
вертикали блок вдвое выше, чем по горизонтали, потому что символ в терминале
примерно вдвое выше своей ширины, — иначе рисунок был бы вытянут. Средняя яркость
выбирает символ из палитры `@%#*+=-:. `: от самого «плотного» для тёмных мест до
пробела для светлых.

Ошибки (нет файла, не BMP, сжатый или обрезанный файл) обрабатываются сообщением.

## Формат входных и выходных данных

Входные данные — путь к BMP-файлу (по умолчанию `image.bmp`, пример приложен), путь к
файлу результата (по умолчанию `ascii.txt`) и ширина рисунка в символах (по умолчанию 80).
Выходные данные — ASCII-рисунок в консоли и в текстовом файле.

## Запуск

Нужен Zig **0.17** (API стандартной библиотеки Zig сильно меняется между версиями, в
других версиях код может не собраться). Проще всего поставить через pip:
`pip install ziglang==0.17.0`, тогда компилятор запускается как `python3 -m ziglang`.

```bash
zig build-exe bmp2ascii.zig -O ReleaseSafe
./bmp2ascii image.bmp ascii.txt 60
```
