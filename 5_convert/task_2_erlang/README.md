# Конвертер CSV в таблицу Markdown

**Тема:** Конвертация данных — Erlang

## Описание задачи

Программа читает CSV-файл, где поля разделены запятыми, а поля, содержащие запятую,
перевод строки или кавычку внутри себя, заключены в двойные кавычки (со стандартным
для CSV удвоением кавычек `""` для экранирования кавычки внутри значения). Собственный
построчный (посимвольный внутри строки, с учётом состояния «внутри кавычек»)
разборщик выделяет отдельные ячейки каждой строки CSV. Первая строка файла считается
заголовком таблицы.

Далее программа формирует Markdown-таблицу: строку заголовка через `|`,
строку-разделитель из дефисов под каждым столбцом и по одной строке Markdown на
каждую строку данных CSV, с вычислением одинаковой ширины столбцов для аккуратного
визуального выравнивания (дополнение пробелами до максимальной длины значения в
столбце). Готовая таблица выводится на экран и сохраняется в `.md`-файл.

## Формат входных и выходных данных

Входные данные — CSV-файл с заголовком в первой строке.
Выходные данные — Markdown-файл с таблицей и тот же текст на экране.
