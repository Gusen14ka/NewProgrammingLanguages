# Конвертер CSV в таблицу Markdown

**Тема:** Конвертация данных — Erlang

## Описание задачи

Программа переводит таблицу из формата CSV в таблицу Markdown. Разбор CSV написан
вручную, без библиотек.

CSV — текстовая таблица, где значения в строке разделены запятыми. Если значение само
содержит запятую, перевод строки или кавычку, оно заключается в двойные кавычки, а
кавычка внутри записывается двумя кавычками подряд (`""`). Поэтому разбор идёт не
построчно, а посимвольно, через конечный автомат — функция `parse` помнит, находится
ли она внутри кавычек. Так корректно обрабатываются запятые и переводы строк внутри
значений. Поддерживаются окончания строк и Unix (`\n`), и Windows (`\r\n`).

Первая строка считается заголовком. Строки с недостающими ячейками дополняются
пустыми. При записи в Markdown символ `|` внутри ячейки экранируется (`\|`), чтобы
не ломать таблицу, а перевод строки заменяется на `<br>`.

Ширина каждого столбца считается по самому длинному значению, и ячейки дополняются
пробелами — таблица выглядит ровно и в обычном текстовом виде. Если все значения в
столбце — числа, он выравнивается по правому краю (в Markdown это `---:` в строке-
разделителе), остальные — по левому.

## Формат входных и выходных данных

Входные данные — CSV-файл (аргумент, по умолчанию `data.csv`, пример приложен).
Выходные данные — Markdown-таблица на экране и в файле (второй аргумент, по умолчанию
то же имя с расширением `.md`).

## Запуск

Нужен Erlang/OTP (`sudo apt install erlang`). Программа — escript, то есть скрипт,
который запускается без отдельной компиляции.

```bash
escript csv2md.erl data.csv
escript csv2md.erl my.csv table.md
```
