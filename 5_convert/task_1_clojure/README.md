# Конвертер INI-файлов в JSON

**Тема:** Конвертация данных — Clojure

## Описание задачи

Программа переводит файл настроек в формате INI в формат JSON. Оба разбора —
и чтение INI, и формирование JSON — написаны вручную, без библиотек.

INI — простой формат конфигурационных файлов:

- `[имя]` — начало секции;
- `ключ = значение` — параметр внутри текущей секции (пробелы по краям обрезаются,
  разделителем считается первый `=`, поэтому в значении `=` допустим);
- строки, начинающиеся с `;` или `#`, — комментарии; пустые строки пропускаются;
- параметры до первой секции попадают в секцию `default`.

Строки, которые не подходят ни под одно правило, пропускаются с предупреждением в
поток ошибок, где указан номер строки. Повторный ключ в той же секции заменяет
прежнее значение. Порядок секций и ключей сохраняется таким же, как в исходном файле.

Результат — JSON-объект `{"секция": {"ключ": значение}}` с отступами. Значения,
похожие на числа (`8080`, `2.5`), и `true`/`false` записываются как числа и логические
значения JSON, остальные — как строки. Специальные символы в строках экранируются
(`"` → `\"`, `\` → `\\`, переводы строк, табуляция), поэтому результат — всегда
корректный JSON.

## Формат входных и выходных данных

Входные данные — INI-файл (аргумент, по умолчанию `config.ini`, пример приложен).
Выходные данные — JSON на экране и в файле (второй аргумент, по умолчанию то же имя с
расширением `.json`).

## Запуск

Нужны Clojure и Java (`sudo apt install clojure`).

```bash
clojure ini2json.clj config.ini
clojure ini2json.clj my.ini result.json
```

Если установлен официальный Clojure CLI вместо пакета из apt, команда:
`clojure -M ini2json.clj config.ini`.
