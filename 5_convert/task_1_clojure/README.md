# Конвертер INI-файлов в JSON

**Тема:** Конвертация данных — Clojure

## Описание задачи

Программа читает файл в формате INI, состоящий из секций вида `[имя_секции]`, за
которыми следуют строки `ключ=значение`, а также строк-комментариев, начинающихся с
`;` или `#` (игнорируются), и пустых строк. Собственный построчный парсер (без готовых
библиотек парсинга INI или JSON) распознаёт начало новой секции, пары ключ-значение
внутри текущей секции (с обрезкой пробелов по краям) и накапливает результат во
вложенную структуру: «секция» → «ключ» → «значение».

По завершении разбора структура сериализуется вручную в текст в формате JSON:
`{"секция1": {"ключ1": "значение1", ...}, "секция2": {...}, ...}`, с корректным
экранированием специальных символов внутри строковых значений (кавычки, обратный
слеш, переводы строк) и читаемыми отступами. Результат выводится на экран и
сохраняется в отдельный `.json`-файл.

## Формат входных и выходных данных

Входные данные — INI-файл.
Выходные данные — эквивалентный JSON-файл и вывод того же JSON на экран.
