# Сервер очереди задач с воркерами-процессами

**Тема:** Клиент-серверное взаимодействие — Elixir

## Описание задачи

TCP-сервер принимает от клиентов текстовые «задания» — простые вычислительные
команды (например, разложение числа на простые множители, вычисление n-го числа
Фибоначчи, сортировка списка чисел) в виде строки `<команда> <аргументы>`. Полученные
задания складываются во внутреннюю очередь процесса-диспетчера.

Заранее запущенный пул процессов-воркеров (акторная модель Elixir/BEAM, только
`gen_tcp` и стандартные процессы, без сторонних библиотек) забирает задания из
очереди по мере освобождения, выполняет вычисление и отправляет результат обратно
диспетчеру, который пересылает ответ соответствующему клиенту по его TCP-соединению.
Диспетчер отслеживает, какой воркер занят каким заданием, чтобы направить ответ
нужному клиенту, даже если несколько клиентов отправили задания одновременно, а
воркеры завершают их в другом порядке. Сервер печатает в лог информацию о принятых и
выполненных заданиях.

## Формат входных и выходных данных

Входные данные — текстовые команды заданий, отправляемые клиентами по TCP.
Выходные данные — результат вычисления, отправленный клиенту; серверный лог с
информацией об обработке заданий.
