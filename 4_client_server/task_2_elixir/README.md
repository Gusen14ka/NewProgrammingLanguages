# Сервер очереди задач с воркерами-процессами

**Тема:** Клиент-серверное взаимодействие — Elixir

## Описание задачи

TCP-сервер принимает от клиентов текстовые вычислительные задания и выполняет их
пулом процессов-воркеров. Сервер и клиент — один скрипт, режим выбирается аргументом.
Используются только стандартные средства Elixir/Erlang: `:gen_tcp` для сети и
легковесные процессы виртуальной машины BEAM для параллелизма.

Поддерживаемые задания:

- `fib N` — N-е число Фибоначчи (длинная арифметика, любые размеры);
- `factor N` — разложение на простые множители;
- `primes N` — количество простых чисел до N;
- `sort a b c ...` — сортировка списка чисел;
- `sleep MS` — «долгое» задание, чтобы показать параллельную работу.

Архитектура построена на акторной модели: процессы не имеют общей памяти и общаются
только сообщениями.

- **Процесс-сессия** — по одному на каждое TCP-соединение. Принимает строки от
  клиента, отправляет их диспетчеру и пересылает клиенту ответы.
- **Диспетчер** — один процесс, хранит очередь заданий и список свободных воркеров.
  Получив задание, присваивает ему номер, кладёт в очередь и отдаёт первому
  свободному воркеру.
- **Воркеры** — фиксированный пул (по умолчанию 3). Воркер выполняет задание, отправляет
  результат прямо сессии нужного клиента и сообщает диспетчеру, что снова свободен.

Клиент сначала получает подтверждение «задание N принято», а результат — когда он
готов. Поэтому быстрые задания возвращаются раньше медленных, отправленных до них.
Ошибки (неизвестная команда, не число) возвращаются как обычный ответ.

## Формат входных и выходных данных

Входные данные — для сервера порт и число воркеров (по умолчанию 7979 и 3), для
клиента адрес и порт; задания вводятся построчно.
Выходные данные — подтверждения и результаты у клиента, журнал очереди и воркеров на
сервере.

## Запуск

Нужен Elixir (`sudo apt install elixir`).

```bash
elixir task_server.exs server          # терминал 1
elixir task_server.exs client          # терминал 2
```
