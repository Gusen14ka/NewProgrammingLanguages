# Эхо-сервер с журналированием обращений

**Тема:** Клиент-серверное взаимодействие — Scheme (GNU Guile)

## Описание задачи

TCP-сервер, который отвечает на простые текстовые команды, и консольный клиент к
нему. Сервер и клиент — один скрипт, режим выбирается аргументом. Используются
встроенные в Guile средства работы с сокетами и потоками.

Команды (регистр команды не важен):

- `ECHO <текст>` — вернуть текст без изменений;
- `UPPER <текст>` — вернуть текст в верхнем регистре;
- `TIME` — вернуть текущее время сервера;
- `QUIT` — попрощаться (`BYE`) и закрыть соединение.

На любую другую команду сервер отвечает сообщением об ошибке со списком доступных
команд. Каждый клиент обслуживается в отдельном потоке, поэтому подключаться можно
одновременно.

Каждое обращение — включая ошибочные — записывается в файл-журнал `server.log` в режиме
дозаписи: время, адрес и порт клиента, команда и отправленный ответ. Запись в журнал
защищена мьютексом, чтобы строки от разных клиентов не перемешались. Те же записи
печатаются в консоль сервера.

Клиент читает команды с клавиатуры, отправляет их серверу и печатает ответы; после
`QUIT` завершается.

## Формат входных и выходных данных

Входные данные — для сервера порт (по умолчанию 8080), для клиента адрес и порт;
команды с консоли клиента.
Выходные данные — ответы сервера у клиента, журнал `server.log` и консоль сервера.

## Запуск

Нужен GNU Guile (`sudo apt install guile-3.0`).

```bash
guile echo.scm server          # терминал 1
guile echo.scm client          # терминал 2
cat server.log
```
