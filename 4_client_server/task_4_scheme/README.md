# Эхо-сервер с журналированием обращений

**Тема:** Клиент-серверное взаимодействие — Scheme

## Описание задачи

TCP-сервер обрабатывает три вида текстовых команд от клиентов: `ECHO <текст>` —
вернуть клиенту тот же текст без изменений; `TIME` — вернуть текущее серверное время;
`UPPER <текст>` — вернуть текст, переведённый в верхний регистр.

Для каждого поступившего запроса, независимо от его типа и результата обработки
(включая нераспознанные команды, на которые сервер отвечает сообщением об ошибке), на
сервере формируется запись в файле-журнале: адрес и порт клиента, время получения
запроса, текст команды и отправленный ответ. Журнал ведётся в режиме дозаписи, так что
со временем накапливается полная история обращений к серверу. Клиентская часть
демонстрационно подключается к серверу, отправляет несколько команд разных типов
подряд (в том числе намеренно некорректную) и печатает полученные ответы на экран.

## Формат входных и выходных данных

Входные данные — команды `ECHO`, `TIME`, `UPPER`, отправляемые клиентом по TCP.
Выходные данные — ответы сервера клиенту; накапливаемый файл-журнал обращений на
сервере.
