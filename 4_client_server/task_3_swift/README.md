# Сервер синхронизации общего счёта для нескольких клиентов

**Тема:** Клиент-серверное взаимодействие — Swift

## Описание задачи

Сервер хранит одно общее значение — «счёт» (целое число), который могут менять сразу
несколько подключённых клиентов. Сервер и клиент — одна программа, режим выбирается
аргументом. Сеть реализована на POSIX-сокетах из системной библиотеки (Glibc в Linux,
Darwin в macOS), потоки и блокировка — из Foundation.

Команды клиента:

- `+N` — увеличить счёт на N;
- `-N` — уменьшить счёт на N;
- `GET` — узнать текущий счёт (ответ только этому клиенту);
- `QUIT` — отключиться.

Каждый клиент обслуживается в отдельном потоке. Счёт и список подключённых клиентов
хранятся в классе `Scoreboard`, все обращения к ним идут под блокировкой `NSLock`,
поэтому одновременные изменения от разных клиентов не теряются. После каждого
изменения сервер рассылает новое значение **всем** подключённым клиентам с указанием,
кто его изменил; так же всем сообщается о подключении и отключении игроков. Так у
каждого участника всегда согласованное представление о счёте.

Клиент в отдельном потоке печатает всё, что приходит от сервера (в том числе
изменения от других игроков), а в основном — отправляет введённые команды.

## Формат входных и выходных данных

Входные данные — для сервера порт (по умолчанию 9090), для клиента адрес и порт;
команды `+N`, `-N`, `GET`, `QUIT` с консоли.
Выходные данные — рассылаемые всем клиентам сообщения об изменениях счёта; журнал
рассылок на сервере.

## Запуск

Нужен Swift для Linux (установка: https://www.swift.org/install/linux/ — например
через `swiftly`) или Xcode в macOS.

```bash
swiftc -O main.swift -o score
./score server                # терминал 1
./score client                # терминал 2
./score client                # терминал 3
```
