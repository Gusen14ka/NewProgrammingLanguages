# Сервер синхронизации общего счёта для нескольких клиентов

**Тема:** Клиент-серверное взаимодействие — Swift

## Описание задачи

Сервер поддерживает единое общее значение «счёта» (целое число), к которому
одновременно могут подключаться несколько клиентов по TCP. Каждый клиент может
отправить серверу команду `+N` (увеличить счёт на N), `-N` (уменьшить счёт на N) или
`GET` (запросить текущее значение без изменения).

Доступ к общему значению счёта на сервере защищён от гонок при параллельной обработке
нескольких клиентов (через блокировку вокруг разделяемого состояния). После каждого
изменения счёта сервер широковещательно рассылает новое значение всем подключённым в
данный момент клиентам, не только тому, кто прислал команду, — чтобы у всех
участников было согласованное представление о текущем состоянии. Клиент выводит на
экран все получаемые от сервера обновления счёта, включая инициированные другими
клиентами.

## Формат входных и выходных данных

Входные данные — команды `+N`, `-N`, `GET`, вводимые с консоли клиента и
отправляемые серверу.
Выходные данные — рассылаемые сервером всем клиентам текущие значения счёта,
отображаемые в консоли клиента.
