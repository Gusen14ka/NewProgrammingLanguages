# Сервер для игры в крестики-нолики между двумя клиентами

**Тема:** Клиент-серверное взаимодействие — Rust

## Описание задачи

TCP-сервер организует многопользовательскую игру в крестики-нолики (3×3) между
парами клиентов. При подключении нового клиента сервер помещает его в очередь
ожидания; как только накапливается два ожидающих клиента, для них создаётся новая
игровая сессия в отдельном потоке: сервер присваивает игрокам символы `X` и `O`,
поочерёдно принимает от текущего игрока номер клетки для хода, проверяет корректность
хода (клетка на поле, клетка свободна) и рассылает обоим игрокам сессии обновлённое
состояние поля.

После каждого хода сервер проверяет условия победы по всем линиям и диагоналям, а
также ничью при заполнении поля без победителя, уведомляет обоих клиентов о
результате и завершает сессию. Несколько игровых сессий выполняются одновременно в
разных потоках, не мешая друг другу; общая очередь ожидания защищена от гонок при
параллельном подключении новых клиентов.

## Формат входных и выходных данных

Входные данные — TCP-подключения клиентов и вводимые ими номера клеток.
Выходные данные — сообщения клиентам о текущем состоянии поля, приглашение сделать
ход, итоговый результат игры (победа/ничья).
