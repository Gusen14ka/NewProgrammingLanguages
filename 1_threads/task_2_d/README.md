# Оценка числа π методом Монте-Карло в потоках

**Тема:** Многопоточность — D

## Описание задачи

Программа оценивает значение числа π статистическим методом Монте-Карло с
использованием нескольких потоков стандартной библиотеки D (`core.thread`). Общее
количество случайных точек делится поровну между потоками. Каждый поток независимо
генерирует свою порцию случайных точек (x, y) в квадрате [-1, 1] x [-1, 1] (со своим
генератором случайных чисел, чтобы избежать гонок при генерации), считает, сколько из
них попало внутрь единичного круга (x² + y² ≤ 1), и сохраняет локальный счётчик.

После завершения всех потоков (join) главный поток суммирует локальные счётчики под
мьютексом, вычисляет итоговую оценку π = 4 × (точки внутри круга) / (всего точек) и
печатает результат вместе с отклонением от эталонного значения. Программа
поддерживает запуск с разным числом потоков (1, 2, 4, 8) и печатает время выполнения
для каждого случая, чтобы показать ускорение.

## Формат входных и выходных данных

Входные данные — общее число точек и список вариантов количества потоков (в коде
или через аргументы командной строки).
Выходные данные — для каждого количества потоков: оценка π, отклонение от точного
значения и время работы в миллисекундах.
