# Оценка числа π методом Монте-Карло в потоках

**Тема:** Многопоточность — D

## Описание задачи

Программа приближённо вычисляет число π методом Монте-Карло, то есть с помощью
случайных чисел. В квадрат со стороной 2 (от −1 до 1 по обеим осям) случайно
«бросаются» точки, и считается, сколько из них попало внутрь вписанного круга
радиуса 1 (условие x² + y² ≤ 1). Площадь круга равна π, площадь квадрата — 4, поэтому
доля попавших точек примерно равна π / 4, откуда π ≈ 4 × (попаданий) / (всего точек).

Работа делится между потоками стандартной библиотеки D (`core.thread.Thread`).
Каждый поток получает свою порцию точек и свой генератор случайных чисел, считает
попадания в локальную переменную и только в самом конце один раз прибавляет свой
результат к общему счётчику. Это прибавление защищено мьютексом
(`core.sync.mutex.Mutex` — объект, который пускает к общим данным только один поток за
раз), чтобы два потока не испортили сумму, записывая её одновременно.

Расчёт повторяется для 1, 2, 4 и 8 потоков на одном и том же общем числе точек, и для
каждого варианта печатается полученное значение π, его отклонение от точного и время
работы — так видно ускорение от распараллеливания.

## Формат входных и выходных данных

Входные данные — необязательный аргумент командной строки: общее число точек
(по умолчанию 40 000 000).
Выходные данные — таблица: число потоков, оценка π, погрешность, время в миллисекундах.

## Запуск

Нужен компилятор D — LDC (`sudo apt install ldc`).

```bash
ldc2 -O3 app.d -of=pi
./pi              # 40 000 000 точек
./pi 100000000    # своё число точек
```
