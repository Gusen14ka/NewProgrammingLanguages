# Ограниченный буфер производитель–потребитель для показаний датчиков

**Тема:** Многопоточность — Nim

## Описание задачи

Симуляция системы сбора данных с нескольких «датчиков». Запускается несколько
потоков-производителей (например, 3), каждый из которых периодически генерирует
случайное значение показания «своего» датчика и кладёт его в общий кольцевой буфер
ограниченного размера (например, 10 элементов). Если буфер полон, поток-производитель
блокируется на условной переменной до появления свободного места.

Один поток-потребитель извлекает значения из буфера по мере их появления
(блокируется на условной переменной, если буфер пуст), накапливает статистику по
каждому датчику (количество показаний, минимум, максимум, среднее) и периодически
печатает текущую сводку в консоль. Синхронизация доступа к буферу и к статистике
реализована через примитивы `Lock` и `Cond` стандартной библиотеки Nim, без сторонних
библиотек параллелизма. Программа завершается после того, как все производители
сгенерировали заданное число показаний, а потребитель обработал их все — после чего
печатается финальный отчёт по каждому датчику.

## Формат входных и выходных данных

Входные данные — число датчиков, размер буфера, число показаний на датчик
(константы в коде).
Выходные данные — периодические промежуточные сводки и финальный отчёт со
статистикой по каждому датчику.
