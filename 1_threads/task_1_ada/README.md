# Параллельная сортировка слиянием на задачах

**Тема:** Многопоточность — Ada

## Описание задачи

Программа принимает (генерирует) массив из N целых чисел. Массив рекурсивно делится
пополам на подмассивы, пока размер подмассива не станет меньше заданного порога
(например, 1000 элементов). Каждая половина сортируется параллельно: для этого
запускается отдельная Ada-задача (task) в модели рандеву, которая сортирует свою
часть массива любым простым алгоритмом (например, quicksort), применённым уже без
порождения новых задач, чтобы не переполнить систему задачами. После завершения
работы обеих задач главная задача выполняет слияние (merge) двух отсортированных
половин в общий буфер.

Глубина параллельного дерева задач ограничивается (например, не более 4 уровней
распараллеливания), дальше используется обычная последовательная сортировка.
Программа выводит: время выполнения последовательной сортировки того же массива,
время выполнения параллельной сортировки, а также проверку корректности результата
(что массив действительно отсортирован по неубыванию).

## Формат входных и выходных данных

Входные данные — размер массива N и диапазон случайных чисел (константы в коде или
аргументы командной строки).
Выходные данные — время работы обеих версий в миллисекундах, флаг корректности
сортировки и (опционально) сам отсортированный массив.
