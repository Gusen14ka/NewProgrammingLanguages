# Параллельная сортировка слиянием на задачах

**Тема:** Многопоточность — Ada

## Описание задачи

Программа генерирует массив из N случайных целых чисел и сортирует его сортировкой
слиянием (merge sort) двумя способами — последовательно и параллельно — после чего
сравнивает время работы.

Параллельная версия рекурсивно делит массив пополам. Левая половина отдаётся новой
Ada-задаче (`task` — встроенный в язык поток выполнения), правая сортируется в текущей
задаче. Задачи общаются через механизм рандеву (`entry`/`accept` — точка встречи двух
задач): через `Start` дочерняя задача получает границы своего куска, через `Finish`
родитель дожидается её завершения. После этого две отсортированные половины сливаются
(`Merge`) в одну.

Глубина распараллеливания ограничена (по умолчанию 3 уровня, то есть до 8 задач):
ниже этого уровня, а также для кусков меньше 10 000 элементов используется обычная
последовательная сортировка, чтобы не тратить время на создание лишних задач.
Обе версии сортируют одну и ту же копию исходного массива, после каждой проверяется,
что результат действительно отсортирован.

## Формат входных и выходных данных

Входные данные — необязательные аргументы командной строки: размер массива N
(по умолчанию 2 000 000) и глубина распараллеливания (по умолчанию 3).
Выходные данные — время последовательной и параллельной сортировки в миллисекундах,
флаг корректности для каждой, ускорение (во сколько раз параллельная быстрее);
при N ≤ 30 печатается сам отсортированный массив.

## Запуск

Нужен компилятор GNAT (`sudo apt install gnat`).

```bash
gnatmake -O2 main.adb
./main               # 2 000 000 элементов, глубина 3 (до 8 задач)
./main 5000000 4     # свой размер массива и глубина
./main 20 2          # маленький массив — печатается результат
```
