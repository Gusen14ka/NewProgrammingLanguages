# Параллельное умножение матриц через fork и каналы

**Тема:** Многопоточность — Perl

## Описание задачи

Программа умножает две матрицы согласованных размеров, заданные либо генерируемые
случайно, либо считываемые из текстового файла. Строки результирующей матрицы
распределяются между несколькими дочерними процессами, порождаемыми через `fork`:
каждый дочерний процесс отвечает за вычисление своего подмножества строк результата
обычным тройным вложенным умножением.

Обмен данными между процессами реализован через каналы (`pipe`), поскольку у
процессов, в отличие от потоков, нет общей памяти: дочерний процесс сериализует
вычисленные строки в текстовом виде и пишет их в канал, родительский процесс читает и
собирает итоговую матрицу. После сборки результата параллельной версией программа
также считает произведение той же пары матриц последовательно в одном процессе и
сверяет оба результата на совпадение (проверка корректности), а также печатает время
выполнения обеих версий.

## Формат входных и выходных данных

Входные данные — размеры матриц и способ их получения (генерация случайных чисел
или чтение из файла с числами).
Выходные данные — итоговая матрица (или её часть при больших размерах), результат
сверки последовательной и параллельной версии, время выполнения каждой.
