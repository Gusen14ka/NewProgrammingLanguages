# Параллельное умножение матриц через fork и каналы

**Тема:** Многопоточность — Perl

## Описание задачи

Программа генерирует две квадратные матрицы N×N из случайных целых чисел от 0 до 9 и
перемножает их двумя способами — последовательно в одном процессе и параллельно в
нескольких процессах, — после чего сравнивает время и проверяет, что результаты
совпадают.

Каждая строка результата C = A × B вычисляется независимо от остальных (строка i
матрицы C зависит только от строки i матрицы A и всей матрицы B). Поэтому строки
делятся на равные блоки, и каждый блок отдаётся отдельному дочернему процессу,
созданному системным вызовом `fork` (он создаёт копию текущего процесса со всеми его
данными, включая матрицы A и B).

В отличие от потоков, у процессов нет общей памяти: то, что дочерний процесс
посчитал, родитель сам по себе не увидит. Поэтому результат передаётся через канал
(`pipe` — однонаправленная «труба» между процессами: один пишет, другой читает).
Дочерний процесс записывает свои строки в канал как текст, родитель читает каналы
всех детей и собирает итоговую матрицу, после чего дожидается завершения каждого
ребёнка (`waitpid`).

## Формат входных и выходных данных

Входные данные — необязательные аргументы командной строки: размер матриц N
(по умолчанию 200) и число процессов (по умолчанию 4).
Выходные данные — время последовательного и параллельного умножения, ускорение,
результат сверки; при N ≤ 6 дополнительно печатаются матрицы A, B и их произведение.

## Запуск

Нужен интерпретатор Perl (в Linux/WSL обычно уже установлен).

```bash
perl matmul.pl          # 200×200, 4 процесса
perl matmul.pl 300 8    # свой размер и число процессов
perl matmul.pl 3 2      # маленькие матрицы — печатаются целиком
```
